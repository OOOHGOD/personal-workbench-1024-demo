# 个人工作台 · 1024 投稿演示

把今日行动、项目推进和月度成果串成一条工作流。

## 打开与体验

在线体验：https://ooohgod.github.io/personal-workbench-1024-demo/ 。本地下载后双击 `index.html`。全部初始数据均为虚构演示内容；无需登录，不读取作者账号或业务云表。

1. 「今日工作」查看今日重点、逾期任务、跟进事项与项目卡点。
2. 顶部输入一句话，点「记下来」，到任务的「收集箱」继续整理。
3. 「日报周报」点「今天」或「本周」，查看自用版与领导摘要；可编辑、导出 Word / Markdown、保存到本机。
4. 「简历月更」点「一键汇总本月证据」，再生成草稿、存为版本快照。
5. 「数据与设置」导出 JSON 备份，或导入此前的备份。

## 功能

- 任务：优先级、状态、计划日期与截止日期分开记录，支持顺延、等待跟进和今日重点。
- 项目：当前阶段、下一步、目标与卡点，按项目关联任务。
- 需求调研：区分已确认需求和待验证想法。
- 速记与资料：灵感、标签、链接和相对路径索引。
- 日报周报：从完成记录与手工 AI 协作记录生成两种报告草稿。
- 个人学习与申请：进度、学习时长、材料清单与临近截止提醒。
- 简历月更：成果证据汇总、月度草稿、版本快照。
- 界面：Bento 布局、可整理小组件、桌面与移动端导航。

## 本投稿版的数据边界

此版本由原作品脱敏后独立生成，替换为 localStorage 数据适配层；它不连接 WorkBuddy SDK，不含真实云表或空间标识。数据保存在当前浏览器，清除网站数据会丢失本机记录；跨设备迁移需自行导出/导入 JSON。示例数据也纳入本版演示统计，以便评审直接体验完整流程。

报告属于规则汇总草稿，需要人工核对。AI 协作记录需要手动填写，不会自动读取任何聊天记录。学习、申请内容默认仅进入自用报告。
